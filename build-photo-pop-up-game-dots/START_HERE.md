# 照片变互动立体书 · Dots 一站式版

用照片、录音和故事制作能探索、能完成任务、能重玩的纸片立体书。集中收集一次必要背景，再由 Dots 负责素材准备、游戏制作、测试和交付。

## 先试玩

- `examples/atlas.html`：三组跨页的探索地图册，含地点、顺序/收集任务及合成测试音。
- `examples/demo.html`：单跨页几何图形示例。

双击 HTML 即可打开。自行构建需要 Python 3.9+；Node 用于运行测试。

## 开始制作

让助手读取 `SKILL.md`，或通过客户端支持的技能入口导入本包；更新已有技能时先保留副本。提供少量清晰照片、可选录音、用途和玩家目标，指出需要准确保留的文字、人物与地点。

可以这样开始：

> 请用这个 skill，把我的照片和录音做成可玩的地图册立体书。先确认用途和素材，其余细节合理默认，交付离线 HTML、源码和验证报告。

代理负责参考照片、调用可用图片工具制作纸片、整理音频、搭建场景和验证。离线构建器负责把准备好的素材打包进游戏；图片处理步骤见 `references/assets-audio.md`，地图册配置见 `references/atlas.md`。

## 交付与分享

交付包含可玩的 HTML、项目源码、素材说明和验证报告。按需要提供本地文件或经授权的公开链接。制作前约定费用和交付范围；分享前核对素材权限、公开范围与元数据，保留私人原件和项目记录。

Three.js MIT 许可位于 `assets/starter/vendor/THREE-LICENSE.txt`；其他素材沿用各自授权。测试覆盖和待验证项目统一见 `references/validation.md`。
