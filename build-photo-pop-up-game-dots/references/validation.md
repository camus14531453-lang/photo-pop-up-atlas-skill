## 新增

多跨页 maps/pieces/game 配置、前后翻页、展开后纸片立起、地点说明/音频、收集与顺序路线任务、跨页完成计数、单页/整本重玩。翻页为合拢—换页—展开动画，不是真实纸张卷曲物理。状态存于内存，刷新清空。

保留 v1.1 的无障碍图片与文字线索、窄屏取景、sRGB/光照、整数 schemaVersion 校验、相对媒体路径与符号链接隔离、签名/大小限制、文本安全嵌入、输出覆盖保护、Three.js 版本与 MIT 许可。两份共享核心一致。修复翻页中切换回退造成动画状态卡住的边界，以及异步旧纹理回调污染新跨页的风险。

制作流程明确区分图片工具和离线代码：代理负责参考照片、实际生成/编辑工具调用、音频整理、地图与游戏集成，但本轮演示仅使用程序地图、透明信标与合成测试音，未执行 AI 图片生成或真实用户素材处理。没有使用私人农场素材。

## 验证结果

- 两版各 20 项 Python 测试通过：原 15 项 + 5 项 atlas 安全/结构回归。
- 两版 Node 状态测试通过（含 20 次重玩）。
- 两版模拟 DOM/音频测试通过；新增跨页测试包含 20 次往返、页内 ID 隔离、完成状态保留、单页/整本重置、音频取消。明确为模拟，不作为浏览器证据。
- 实际 ChatGPT 内置 Chromium 浏览器：三页连续前后翻页；额外 3 轮往返；重复点击；错误顺序提示与恢复；3/3 完成后返回保留；Enter 单页重玩从 3/3 到 2/3，整本重玩到 0/3；回退地图/图片/线索；翻页中切回退；模拟 prefers-reduced-motion 下键盘即时换页，测试后恢复。
- 390×844 浏览器视口：实测 innerWidth=390、scrollWidth=390；画面及控件可用，截图见 narrow-3d.png。是桌面浏览器视口，不是实体手机。
- 真实 HTMLAudioElement 解码及播放：readyState=4、paused=false、currentTime=0.169068；切页后 currentAudio=null。没有人工听感验收，不声称真实人声或扬声器输出已验证。
- 浏览器控制台未观察到 error/warn。
- 两包 ZIP 回读、解包后构建两种示例，与包内 HTML 字节一致；源交接哈希不变。
- 文本扫描未命中姓名、本机用户目录或农场内容；不代表未来用户素材自动获准发布。
