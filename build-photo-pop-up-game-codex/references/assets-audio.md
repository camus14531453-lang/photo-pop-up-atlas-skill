# Prepare images and audio

## Images

Inspect each source image: subject, orientation, useful crop, identity/geography, exact text and quality. Preserve originals in the private project and record derivatives in the asset inventory.

For AI generation or editing, use the current image tool with actual reference images and the requested transparency. Inspect the returned image for subject fidelity, readable text, dimensions, alpha edges and complete cut-outs. Preserve existing transparency when appropriate. Use verified DOM/SVG text for labels that need exact spelling; ask about unreadable essential wording.

Separate foreground cut-outs, supporting planes and backgrounds to suit the agreed scene depth. Choose resolution from screen size and memory needs. For sprite sheets, keep frame bounds, pivot and padding consistent. Use neutral fixtures for reusable examples.

Before distribution, remove unnecessary personal/location metadata from approved derivatives, inspect the result, and retain provenance privately. The offline builder embeds referenced bytes unchanged; prepare metadata-clean derivatives before building.

## Audio

Inspect available extraction, conversion and transcription tools. Preserve original recordings and select useful intervals; record source, timing, speaker/context, edits and transcript confidence. Keep speech meaning intact. Voice cloning requires separate authorization.

Listen when aligning recordings to scenes. Check clipping, intelligibility, transitions and private background speech. If transcription is unavailable, retain approved playback and add a verified text clue or mark the transcript for review.

Start audio from a user gesture. Handle loading errors, blocked playback and unsupported codecs with a text clue and retry control. Provide mute, captions/equivalent clues and replay. Stop obsolete audio on navigation, restart and page hiding; rapid selections should replace earlier speech. Use conservative volume for generated cues.

Verify playback and interruption in the real browser using the QA matrix. Record decoder/playback checks and listening checks separately in the validation report.

## Rights and delivery scope

Record creator/source, license or user-provided basis, attribution, transformation and distribution permissions, and unresolved rights. Confirm the destination for private people, voices and material before sharing them. Obtain separate authorization for paid actions, new account/access actions and public release.

Package only approved runtime assets, source and credits. Keep private originals, project notes and credentials outside the reusable skill and public export. Retain upstream license notices and identify any outstanding distribution permission in the delivery report.
