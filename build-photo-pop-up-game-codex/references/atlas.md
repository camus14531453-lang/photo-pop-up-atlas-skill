# 多跨页地图册（v1.2）

先集中收集背景：目标与受众、地点/路线、跨页数量、照片与录音、必须准确的地理/文字、玩法、设备和交付范围。已有答案不重复问；未指定时采用三跨页中立探索示例。Codex 入口仍按其专属短轮问答流程执行。

## 制作责任与工具边界

由当前代理负责素材盘点、照片查看、地图底图设计、纸片图片生成/编辑工具调用、透明边缘检查、音频整理、集成与验收，不让用户在多个 AI 之间搬运。调用前确认工具真实可用，并遵循其图片编辑、透明背景、输入引用要求；工具输出必须查看后再使用。用项目资产清单记录原图、派生图、生成/编辑记录、音频字幕及授权范围。

离线构建器只校验并嵌入已经存在的 PNG/JPEG/WebP 和音频；不会调用图片工具、画真实地图、抠图、转录、裁剪音频或生成用户素材。工具不可用时采用适合当前设计的处理方式，或记录需要补齐的素材步骤。真实地图必须核对方位、地名、位置和底图授权；示意图需明确标注。

## 配置

复制 `assets/starter/atlas-demo.json` 和其引用的 `media/` 到独立项目后修改。构建命令同 starter.md。旧版顶层 pieces/game 配置继续支持，不能与 spreads 混用。

顶层保留 schemaVersion（严格整数 1）、title、intro、language、ui，增加 `spreads`（1–24 项）。每项含唯一 id、title、intro、pieces、game；title/intro 可继承顶层。每页 1–16 个地点，piece 字段和安全限制沿用 starter.md；地点 ID 只需在本跨页唯一。

可选 `maps: {"left":"media/left.png", "right":"media/right.png"}` 指定左右底图，提供 maps 时必须含非空 `mapCaption`，说明地图与路线的文字等效信息。PNG/JPEG/WebP 签名、相对路径、符号链接隔离、文件/输出大小校验同地点图片。底图按纸页矩形拉伸；需要精确比例时先准备合适比例的派生图。关键地名用可验证文字标注，不依赖生成图文字。

每项 game 使用 collect 或 sequence 任务。targets 包含该页每个地点恰好一次；sequence 的次序即正确路线。caption 提供地点说明/任务线索，audio 可选但必须有 caption。当前支持发现/收集与顺序路线任务，不包含自由问答、多分支剧情或地理坐标投影。

## 行为

上一/下一跨页采用纸页合拢、换页、展开和纸片立起过渡。需要单张纸卷曲效果时，可在此基础上扩展翻页几何。地图册的纸片在展开后全部立起；旧版示例保持选中后立起。翻页不要求先完成任务；每页状态独立保留，总进度为已完成跨页数。重复点击不重复计数，完成后仍能检查地点/听音。

“重新开始”只重置当前跨页；“重玩整本”重置所有跨页并回到第一页。切页、重玩、关闭声音、隐藏页面都会停止当前声音；快速连续点击替换旧声音。进度仅保存在当前页面内存，刷新清空，不收集数据、不使用后端。键盘用 Tab/Enter；减少动画偏好即时切页。无障碍视图保留地图、图片、文字线索、任务和同一状态。

## 验证与交付

运行 test_builder.py、test_state.cjs、test_ui.cjs、test_atlas_ui.cjs，再按 implementation-qa.md 检查实际浏览器中的翻页、重复点击、任务、重玩、音频、窄屏与键盘操作。将测试方法、结果与待验收项集中记录在项目验证报告；本包记录见 [validation.md](validation.md)。
